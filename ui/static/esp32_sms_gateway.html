SMS-шлюз на базе микроконтроллера ESP32

Автономное устройство с собственной SIM-картой, которое подключается к OpenCARWINGS напрямую и отправляет SMS-команды для TCU, не требуя смартфона или USB-модема. Прошивка выполняется в браузере повторно, без установки SDK.

Прошивка через официальный веб-флашер Espressif (ESP Tool)

Если кнопки «Прошить» недоступны (страница открыта по HTTP, а не HTTPS), используйте официальный онлайн-флашер Espressif — ESP Tool. Он работает в браузере Google Chrome / Microsoft Edge / Opera на компьютере (Safari не поддерживается), прошивка идёт через Web Serial и не требует установки программ.

  1. Скачайте прошивку для своей платы: ESP32-C3 + SIM800 (.bin, ~1.1 МБ) или TTGO T-Call (.bin, ~1.1 МБ).
  2. Подключите плату к компьютеру по USB (C3 — USB-C, T-Call — Micro-USB) и откройте https://espressif.github.io/esptool-js/.
  3. Выберите Baudrate: 921600 (если при подключении будут ошибки — попробуйте 460800).
  4. Нажмите Connect и в диалоге браузера выберите COM-порт платы (для T-Call Chrome покажет «USB Serial / CP2102», для ESP32-C3 — «USB Serial / JTAG»).
  5. Нажмите Add File и выберите скачанный .bin. В строке файла укажите Flash Address: 0x0. Параметры Flash Mode: dio, Flash Size: detect можно не трогать (значения уже записаны в прошивку).
  6. Нажмите Program и дождитесь окончания записи (в консоли появится текст о записи и завершении).
  7. После записи нажмите Reset или заново подключите USB — плата перезагрузится с новой прошивкой.

Примечание: если ESP Tool сообщает «Timed out» и не может записать — плата не вошла в режим загрузчика. Зажмите кнопку BOOT (на T-Call это EN-кластер), нажмите и отпустите RST, затем снова Program. Прошивка полностью перезапишет flash-память платы.

Настройка после прошивки

  1. Вставьте SIM-карту с интернетом. Провайдер GPRS — любой, APN по умолчанию internet (уточните у оператора; можно изменить в настройках).
  2. Подключитесь к Wi-Fi точке устройства ESP32-TCU-SMS (пароль tcu12345), откройте http://192.168.4.1 и перейдите в раздел «Настройка».
  3. Укажите способ подключения к интернету: WiFi (SSID/пароль вашей сети) или SIM-карта (GPRS). Через WiFi работа стабильнее и без задержек; через GPRS — немного медленнее и зависит от качества сигнала сотовой связи. Для GPRS при необходимости укажите APN, логин и пароль.
  4. Заполните поля ретранслятора:
    • Device ID и Encryption key — те же значения, что указаны в настройках вашей машины на сервере (провайдер SMS → поле «Device ID» / «Encryption key»).
    • WebSocket URL — адрес вашего сервера, вставьте готовую строку: ws://138.16.224.7/ws/smsgateway/.
    Нажмите «Сохранить и перезагрузить».
  5. На сервере в настройках машины (раздел SMS provider, тип «Use your old smartphone») укажите те же Device ID и Encryption key, а в поле «Phone number» — номер SIM-карты, установленной в шлюз. Нажмите «Сохранить».
  6. Проверьте статус на http://192.168.4.1 — строка WebSocket: connected. Готово, шлюз принимает команды и отправляет SMS для TCU.

Совет

Для теста подойдёт любая SIM-карта с пакетом интернета — обычно достаточно «SMS-пакета» от вашего оператора. Устройство поддерживает авто-переподключение при обрыве сети и пережидает перезагрузку сервера. Если после настройки нет соединения — проверьте APN и наличие интернета на SIM (пункт меню «Проверить интернет»).

TTGO T-Call v1.3 / v1.4

Готовая плата «всё в одном»: классический ESP32 + встроенный SIM800L, разъём для LiPo, CP2102 (USB-UART).

Скачать .bin
Важно
  • Обязателен LiPo аккумулятор (SIM800L пики ~2А)
  • Модемный UART: GPIO26 (RX) / GPIO27 (TX) — уже в прошивке
  • PWRKEY управляется автоматически
  • USB только для прошивки/консоли (CP2102)
Особенности
  • Работает от встроенного SIM800L напрямую
  • Лог в USB-консоль по CP2102
  • Wi-Fi точка для настройки
  • Совместим с открытым JAR-протоколом
Ваш браузер не поддерживает Web Serial. Используйте Google Chrome или Microsoft Edge.

Плата ESP32-C3 + SIM800

Готовый Ethernet/WS-шлюз на модуле ESP32-C3 (нативный USB-CDC, лог в консоль) с внешним GSM-модулем SIM800L/H/SIM808.

Скачать .bin
Подключение SIM800
  • SIM800 RX ← GPIO4 (ESP32 TX)
  • SIM800 TX → GPIO5 (ESP32 RX)
  • Питание 5В (пики до 2А) — внешний DC-DC
  • Уровни сигналов: SIM800 2.8В, делитель 1.8–3.3В
Особенности
  • Лог в USB-консоль (GPRS, WS, SMS)
  • APN по умолчанию: internet
  • Совместим с открытым JAR-протоколом
  • Wi-Fi точка для настройки
Ваш браузер не поддерживает Web Serial. Используйте Google Chrome или Microsoft Edge.
