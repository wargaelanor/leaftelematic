Инструкция: возвращение навигатора в сеть
(ZE0 и AZE0 2011–2015)

ПРИМЕЧАНИЕ: Эта инструкция для навигационных блоков с двумя SD-слотами за экраном. Если у вас только один слот, следуйте этой инструкции.
Эта подробная инструкция поможет вам изменить настройки APN вашего навигатора. Внимательно следуйте каждому шагу для успешной настройки.

Шаг 1: Скачайте Leaf SD Tools и запишите его на SD-карту

Для экспорта настроек навигатора понадобится набор инструментов Leaf SD Tools. Как действовать:

  • 0:Возьмите SD-карту объёмом от 8 ГБ. Micro SD с переходником тоже подойдёт.
  • 1: Скачайте последний файл Leaf SD Tools .img на GitHub (LeafSDTools-xxx.img.tar.gz)
  • 2: Скачайте balenaEtcher или аналогичную программу для записи образа на SD-карту.
  • 3: Запишите образ диска на SD-карту.

Шаг 2: Запустите LeafSDTools и экспортируйте настройки на SD

Теперь, когда LeafSDTools у вас на SD, выполните следующие действия, чтобы извлечь файл настроек:

  • 1. Заведите автомобиль. После полной загрузки навигатора нажмите кнопку MAP, чтобы открыть вид карты.
  • 2. Нажмите кнопку питания, чтобы выключить звук. Кнопка находится слева внизу.
  • 3. Нажмите три раза кнопку «MAP», затем два раза кнопку включения/выключения медиа и ещё раз кнопку «MAP». При успехе вы увидите этот экран:
  • Откройте меню Confirmation/Adjustment и прокрутите до меню Software Update.
  • Запустите процесс обновления. Головное устройство должно перезагрузиться.
  • Когда появится диалог YES/NO, выключите автомобиль, выньте SD из слота MAP (B) и вставьте свою SD-карту с LeafSDTools.
  • 4. С вставленной в слот B картой LeafSDTools включите автомобиль. Через несколько секунд появится показанный выше экран. Нажмите меню SRAM.
  • 5. Нажмите Dump to SD и дождитесь завершения.
  • 6. После успешного дампа на SD выйдите из меню и выключите автомобиль. Выньте SD-карту из навигационного блока. Теперь файл нужно отредактировать на компьютере.

Шаг 3: Измените настройки навигационного блока

После подключения SD-карты к компьютеру у вас должен появиться файл с именем вида:

Если такого файла нет, экспорт по какой-то причине не удался. Если файл есть, изменим в нём настройки APN.
  • 1. Скопируйте файл vflash_xxxxxxxx_xxxxxxxx.bin с SD-карты куда-нибудь ещё, например, на Рабочий стол или в Документы.
  • 2. Откройте в браузере http://138.16.224.7/navi
  • 3. Выберите файл vflash_xxxxxxxx_xxxxxxxx.bin с вашей SD-карты. В поля должны подставиться данные и появиться «Connection Profile 1». Если этого не произошло, обратитесь к разработчику.
  • 4. Начните с названия профиля подключения — укажите имя вашего оператора.
  • 5. Затем измените имя точки доступа: apn [cws]. В зависимости от SIM-оператора может также понадобиться изменить пользователя и пароль APN: usr [cws] и psswrd [cws].
  • 6. И, наконец, измените адрес сервера. Поле «url [cws]». Стандартный адрес — «http://biz.nissan-gev.com/WARCondelivbas/it-m_gw10/». Измените его на «http://138.16.224.7/WARCondelivbas/it-m_gw10/»
    • Измените поле «url [cws]» на «http://138.16.224.7/WARCondelivbas/it-m_gw10/»
  • 7. После изменения всех настроек прокрутите страницу вниз и нажмите «export». Будет скачан новый файл настроек.
    Скопируйте скачанный файл на SD-карту (при запросе перезаписи нажмите yes)

ПРИМЕЧАНИЕ: При копировании нового файла настроек на SD-карту убедитесь, что имя файла точно такое же, как у оригинала!

Шаг 4: Запишите новые настройки в навигационный блок

С изменённым файлом настроек на SD-карте вернитесь к автомобилю, вставьте карту в слот B и заведите автомобиль.

  • 1. Когда LeafSDTools загрузится, выберите опцию SRAM.
  • 2. Нажмите RESTORE VFlash и дождитесь восстановления.
  • 3. Когда восстановление завершится, нажмите EXIT для возврата в главное меню. После этого выключите автомобиль.
  • 4. Наклоните экран и выньте SD-карту LeafSDTools из слота B. Вставьте обратно в слот B штатную SD-карту навигационного блока. Включите автомобиль — появится это сообщение. Нажмите Yes, чтобы выйти из меню обновления ПО.
  • 5.Когда навигационный блок загрузится в свою ОС, откройте настройки и проверьте, что новые параметры подключения применились. Чтобы увидеть профиль подключения, нажмите физическую кнопку MENU справа и выберите SETTINGS на экране. В настройках выберите «Phone, CARWINGS». Выберите Data Transfer Setup. Если настройки применились успешно, должен отобразиться ваш профиль подключения.

Шаг 5: Авторизуйтесь в меню CARWINGS

Последний шаг — авторизуйтесь с вашим именем пользователя и паролем TCU, созданными в сервисе OpenCARWINGS.

  • 1. Нажмите кнопку Zero Emission и выберите CARWINGS.
  • 2. Нажмите Sign In или Security Settings.
  • 3. Введите ваше имя пользователя и пароль TCU.
  • 4. Нажмите «send security settings» или «send ID and password». Когда появится сообщение «Security settings activated», это означает, что вход выполнен успешно и службы CARWINGS готовы к использованию.

Поздравляем! Если все шаги выполнены успешно, ваш навигационный блок снова в сети, и восстановлены такие функции, как отправка местоположения в автомобиль, телеметрия и многое другое.
