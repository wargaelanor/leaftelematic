API канала данных

Данные канала передаются на сервер в формате JSON. Сервер отправит данные об автомобиле, если разрешение на определённые функции предоставлено.

Запрос от сервера

POST-запрос с JSON-телом:

{
    "lang": "en", // допустимые значения: es, sl, cz, pl, gr, no, fi, se, dk, nl, pt, it, de, fr, ru
    "tz": "0.00",
    "distance_unit": "km", // km или mile
    "temp_unit": "C", // C = Цельсий, F = Фаренгейт
    // Поля выше доступны только при разрешении на передачу местоположения
    "lat": 51.509966666666664,
    "lon": 0.13496111111111112,
    "speed": "err", // err = скорость недоступна, иначе значение в distance_unit
    "direction": "0", // градусы
    "car_status": "stop" // stop = автомобиль на стоянке, run = в движении (D или R)
}

Ожидаемый формат ответа

JSON-массив объектов слайдов (МАКСИМУМ 2 СЛАЙДА):
* = обязательное поле

{
    "title1": "", // * Название слайда (макс. 32 символа)
    "title2": "", // * Описание слайда (макс. 128 символов)
    "title3": "", // Дополнительное описание (макс. 64 символа)
    "onscreen": "", // Текст, отображаемый на экране в меню «Details» (макс. 1024 символа)
    "tts": "", // Текст для озвучивания TTS-движком (допускается XML для движка TTS)
    "map_point": {"lat": 0.0, "lon": 0.0}, // Объект точки на карте с широтой и долготой
    "phone_number": "", // Номер телефона в международном формате
    "img_base64": "", // Изображение в Base64, макс. 15 480 байт. Формат — JPEG или PNG
    "bell": true, // Если true, перед озвучиванием TTS воспроизводится звук объявления (по умолчанию: true)
    "save": true, // Если true, слайды сохраняются в памяти CARWINGS (по умолчанию: true)
}
